# Primary-source acquisition

This directory intentionally contains no mirrored copyrighted translations or scans. The authoritative source register is `../bibliography/sources.json`. The individual dossiers identify primary passages and relevant manuscript or museum designations.

Acquisition checklist: edition and author; ancient language; original text vs reconstruction; transliteration convention; translation license; tablet/manuscript siglum; museum number; excavation/provenance; exact passage coverage; composition and physical-object dating; preservation state; rights and attribution.

Initial primary access includes ETCSL’s composite Sumerian flood text, Hebrew reading editions, Hesiod’s 1914 translation, selected Enuma Elish and Atrahasis translations, a Pyramid Text passage, and a Ugaritic excerpt. These are not all diplomatic transcriptions. Modern syntheses of Hermopolitan, Memphite and Kumarbi material remain marked as historical interpretation until primary collation is completed.
